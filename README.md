

# SellerPilot

## AI-Assisted Ecommerce Operations Platform

SellerPilot is a UX and product design portfolio project exploring how AI can help small ecommerce businesses manage post-purchase customer issues.

## Problem Statement

Small ecommerce sellers may need to switch between different tools to manage orders, shipping updates, and customer inquiries. This project will investigate those challenges and explore ways to simplify issue resolution.

## Project Goals

- Conduct UX research with ecommerce sellers.
- Design intuitive user journeys and interaction flows.
- Explore AI-assisted recommendations with human oversight.
- Build an interactive prototype using React and TypeScript.
- Evaluate usability and improve the experience.

## Planned Tools

Figma, FigJam, React, TypeScript, v0, GitHub, and Vercel.
